====================================================================
      ALONE IN THE ZONE - TOP-DOWN ROGUELITE SHOOTER (JAVA 21)
====================================================================

1. CÁCH CHƠI NHANH:
-------------------
- Cách 1 (Khuyên dùng): Nhấp đúp chuột vào file "RunGame.bat" hoặc "RunAloneInTheZone.bat" để chơi ngay lập tức.
- Cách 2 (Tạo phím tắt Desktop): Nhấp đúp vào file "TaoShortcutDesktop.bat" để tạo ngay Shortcut ra màn hình Desktop kèm biểu tượng Icon Player!
- Cách 3: Nhấp đúp trực tiếp vào file "AloneInTheZone.jar".
- Cách 4: Mở Command Prompt (cmd) hoặc PowerShell tại thư mục này và gõ:
    java -jar AloneInTheZone.jar

* Tự đổi biểu tượng Shortcut thủ công (nếu muốn):
  Chuột phải vào Shortcut trên Desktop -> Properties -> Bấm "Change Icon..." -> Chọn tệp "icon.ico" trong thư mục game -> OK.

* Phân phối 2 gói phát hành chính thức:
  + Bản "AloneInTheZone-ChuaCoJava21.zip" (Trọn gói kèm sẵn thư mục runtime OpenJDK 21): KHÔNG CẦN CÀI ĐẶT BẤT CỨ THỨ GÌ! Máy tính chưa từng cài Java vẫn giải nén bấm chơi được ngay.
  + Bản "AloneInTheZone-DaCoJava21.zip" (Bản siêu nhẹ dành cho máy tính đã cài sẵn Java 21 LTS trở lên).
    Tải Java 21 (nếu cần) tại: https://adoptium.net/temurin/releases/?version=21


2. BẢNG PHÍM ĐIỀU KHIỂN (CONTROLS):
------------------------------------
- [W, A, S, D]       : Di chuyển nhân vật 8 hướng.
- [Di chuột]         : Ngắm bắn 360 độ quanh nhân vật.
- [Chuột trái]       : Bắn vũ khí đang cầm (nhấp phát một hoặc giữ để xả đạn).
- [Chuột phải]       : CẬN CHIẾN NHANH (Vung dao chém lập tức khi đang cầm súng, tăng đẩy lùi).
- [Space] (Phím cách): LƯỚT NÉ ĐÒN CHIẾN THUẬT (Bất tử i-frames trong tích tắc).
- [R]                : Nạp lại băng đạn (Reload magazine).
- [1, 2, Q]          : Chọn slot vũ khí chính 1, slot 2 hoặc đổi nhanh 2 vũ khí.
- [3, 4]             : Chọn súng lục phụ (Slot 3) hoặc dao găm cận chiến (Slot 4).
- [F]                : Tương tác nhặt đồ / Dùng hộp cứu thương / Mua đồ ở Shop / Mở Bảng Nâng Cấp Nhân Vật.
- [Tab] hoặc [B]     : Mở/Đóng Balo chiến thuật (Xem vũ khí và trữ lượng đạn).
- [Esc]              : TẠM DỪNG TRÒ CHƠI / Menu Tùy chọn (Tiếp tục, Cài đặt phím, Thoát).
- [F11 / Alt+Enter]  : Bật / Tắt chế độ Toàn màn hình (Full Screen).
- [Cài đặt phím]     : Tùy biến toàn bộ 16 phím điều khiển ngay tại Menu chính hoặc trong trận.
- [Enter] hoặc [R]   : Chơi lại từ đầu khi tử trận (Game Over).


3. TÍNH NĂNG NỔI BẬT:
---------------------
- Lối chơi hành động Rogue-lite góc nhìn từ trên xuống (Tham chiếu cơ chế hầm ngục từ Soul Knight và cơ chế xạ kích 360 độ, nhặt đạn, phá hòm từ Surviv.io).
- 6 loại khí tài tác chiến chuyên nghiệp:
  + Súng lục P-9 (vô hạn đạn, 7 viên/băng).
  + Súng trường tấn công Viper AR (30 viên/băng, tốc độ 700 RPM, đạn súng trường 150 viên).
  + Súng tiểu liên Spectre SMG (35 viên/băng, tốc độ 900 RPM, đạn SMG 180 viên).
  + Súng bắn đạn hoa cải Bulldog SG (8 viên/băng, 6 viên chì/phát, đạn shotgun 50 viên).
  + SÚNG BẮN TỈA SR BOLT ACTION (5 viên/băng, đạn 1450 px/s, xuyên qua nhiều kẻ địch & cover tạm thời, đạn SR 30 viên).
  + Dao găm chiến thuật Tactical Knife (cận chiến khẩn cấp, đẩy lùi cực mạnh, chặt gãy thùng gỗ).
- Hệ thống đạn dược dự trữ độc lập: Đạn Súng trường (150 viên), Đạn SMG (180 viên), Đạn Shotgun (50 viên), Đạn Bắn tỉa SR (30 viên).
- PHÒNG NÂNG CẤP NHÂN VẬT (Bio-Tech Augmentation Laboratory):
  + Trạm Nâng Cấp Chỉ Số: Tăng % Máu, Tấn công, Tốc độ, Phòng thủ, Giảm hồi chiêu né, May mắn nhặt đồ.
  + Trạm Kỹ Năng Đặc Biệt: Khiên chặn đòn 10s CD, Diệt địch hồi 2.5 HP, Né xuyên vật cản, Thu nhỏ 30% hitbox, Tiếp đạn chu kỳ 30s, Băng đạn mở rộng, Bậc thầy chí mạng (+15% crit).
  + Rút 3 thẻ bài ngẫu nhiên, mua bằng Credits bằng phím [1], [2], [3] hoặc chuột.
- Cửa phòng chiến đấu tự động phong tỏa khi có quái và mở ra khi dọn sạch phòng.
- AI quái cận chiến áp sát chém móng vuốt và lính súng lục biết lùi xe giữ cự ly bắn tỉa.
- Boss khổng lồ Chiến Xa Titan (Boss Tank) bắn đại pháo bộc phá AoE và húc đâm xuyên cover ở Stage 4.
- Cửa hàng Shop và Xưởng Quân Khí Tẩy Luyện Chỉ Số ngẫu nhiên mỗi màn chơi.
